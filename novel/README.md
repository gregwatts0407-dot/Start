# The Same Night, Seven Ways

A literary thriller in seven parts (~249,000 words). One night in October 1994, one house on a tidal island, seven witnesses, seven genres: noir, comedy, gothic, romance, western, scientific romance, and mystery. Every account is true; each contradicts the others; the last makes them fit.

- `manuscript/` — the text, one file per chapter, assembled in filename order
- `notes/bible.md` — continuity bible (contains every spoiler)
- `dist/` — built PDF, DOCX and HTML
- Rebuild with `python3 build.py --all` (needs pandoc, node + playwright)
